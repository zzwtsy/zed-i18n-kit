# 语义示例

这些示例用于校准判断，不是可机械套用的替换模板。每次删改都要先确认原文承载的完整命题。

## 失效引用

### 有已提交所有者的临时编号

泄漏：

> 扫描结果必须固定 Zed commit（decision 4）。

改写：

> 扫描结果必须固定 Zed commit，详见[架构设计的版本快照要求](../../../../docs/zed-gpui-i18n-design.md#45-版本快照与能力探测)。

`decision 4` 只能由作者会话解析；已提交文档的名称和路径可以由当前 checkout 解析。

### 没有所有者的审计编号

泄漏：

> 相同输入必须产生相同输出（audit R3）。

改写：

> 相同输入必须产生相同输出。

编号不承载事实，但确定性约束必须保留。

## PR 和变化叙事

### README 采用 PR 视角

泄漏：

> This PR adds strict validation for golden samples.

改写：

> Golden samples use strict validation.

README 陈述当前机制；PR 自己保存变更历史。

### 回归历史仍有维护价值

泄漏：

> UTF-8 anchor 以前会按字符偏移定位，后来修好了。

改写：

> 缺少 byte offset 校验时，UTF-8 anchor 会定位到错误边界。

现在时反事实保留保护条件和失败后果，不要求读者了解旧实现。

## Reviewer 视角

泄漏：

> 这个转换是安全的；reviewer 已确认输入一定是规范化路径。

改写：

> 调用者只传入已经规范化且位于 checkout 内的相对路径。

正确性来自可核对的不变量，不来自某位 reviewer 的权威。

## 控制流和测试复述

泄漏：

> 先读取 manifest，然后遍历 samples，最后统计每种 decision。

处理：删除。相邻代码已经完整表达这个顺序。

泄漏：

> 该测试加载文件、调用校验器，然后断言异常。

改写：

> 非法 `source_scope` 必须在读取 corpus 时失败，不能进入统计阶段。

保留测试为何需要该断言，而不是复述测试主体。

## 对冲与计划残留

泄漏：

> 250 个样本目前应该够用。

改写：

> 金标语料固定为 250 个样本，并通过 manifest 中的覆盖配额验证代表性。

如果没有配额或其他证据，就不能把“应该够用”伪装成事实；应报告缺少验收依据。

## 应保留的命中

### 已提交的工作项与 ADR

保留：

> ADR 0002 规定金标 schema v1 的兼容边界。

只要文件存在且内容确实拥有该决定，这就是可解析引用。

### 必要的抑制理由

保留并核实理由：

```python
if schema_version == 1:  # noqa: PLR2004 - 1 is the committed wire-format version.
    load_v1(payload)
```

机器指令和真实抑制原因承担维护契约。理由错误时修正理由，不能只为减少文字而删除。

### 带来源的测量边界

保留：

> 64 KiB 上限覆盖当前最大 48 KiB 样本，并为格式扩展保留余量。

数字、观察来源和超限含义应一起保留；缺少来源时先调查，不能擅自补写“实测”。

### 运行时 old/new

保留：

> 新 inventory 写入成功后再删除旧 inventory。

这里的“新/旧”描述同一次运行中的两个对象，不是仓库版本流水账。

## 过度纠正陷阱

### 把义务改成认可

原文：

> 这些规则是等待迁移到 domain rule pack 的例外。

错误改写：

> 这些规则是允许的例外。

正确处理：保留“等待迁移”或链接真实工作项；`允许`改变了原文的义务强度。

### 把假设写成已交付能力

原文：

> 未来的 rust-analyzer sidecar 可以提供 receiver 完整类型。

错误改写：

> rust-analyzer sidecar 提供 receiver 完整类型。

正确改写：

> 如果后续引入 rust-analyzer sidecar，它可以提供 receiver 的完整类型；当前实现不包含该 sidecar。

删除未来标记会把设计选项变成已交付事实。

### 连同叙事删除真实耦合

原文：

> 上一轮评审要求先更新 schema；manifest 校验器也依赖该 schema 的枚举集合。

错误处理：整句删除。

正确改写：

> manifest 校验器依赖 schema 定义的枚举集合。

前半句是评审过程，后半句是当前耦合。

### 删除测量来源

原文：

> 该上限来自测量：最大 corpus 文件为 3.1 MiB。

错误改写：

> 最大 corpus 文件为 3.1 MiB。

正确处理：保留“来自测量”及测量对象；否则观察值会被误读为格式定义。
